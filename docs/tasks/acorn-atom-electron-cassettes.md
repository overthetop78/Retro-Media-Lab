Validation du 2 novembre : 961 tests AcornEmu réussis en 21 s, dont le diagnostic temporaire (depuis supprimé). Les configurations réelles Atom/Electron démarrent par EmulatorCore. La ROM Atom charge un TAP synthétique via les broches cassette et retrouve les 128 octets attendus en RAM. Les deux formats réels TAP/UEF se chargent sans rejet du décodeur BBC ; les 13 TAP de la collection contiennent 29 enregistrements structurellement complets. Les trois tests TAP autonomes restent dans le dépôt. Aucun média ni réglage utilisateur modifié. L'audit des composants et le bloc Archimedes complet restent ouverts.

Constats directs sur l'audit des composants : `Cpu6502.Step` termine encore les instructions par `Pad`, lequel appelle seulement `Tick`, sans effectuer les lectures transitoires du bus. `EnterInterrupt` empile et lit le vecteur puis complète de la même façon les sept cycles. Les instructions non reconnues lèvent toujours une exception dans `Cpu6502.Instructions.cs`. Ces manques sont donc confirmés par le code, indépendamment d'une panne utilisateur reproduite. `Via6522.Tick` ne décrémente T2 que lorsque le mode impulsions est désactivé ; aucune entrée PB6 ne fournit actuellement le décompte de ce mode. Le fichier ne propose pas non plus de gestion complète CB2/handshake. Les corrections de ces composants restent à réaliser, sans les confondre avec les corrections cassette livrables. `Crtc6845` fixe VSYNC à seize lignes ; la décision de rendre cette largeur programmable doit tenir compte du circuit exact utilisé par chaque carte, car les variantes du 6845 ne sont pas équivalentes sur ce point.
