## Réalisation

Aucun décodeur, séquenceur, registre ou CPU n'est dupliqué. Instructions, bus, WAIT, interruptions, HALT, reset et état sont les mécanismes du [Z80 commun](Z80.md).

`Upd780C1Profile.Timing` décrit les limites NEC 4 MHz de la fiche constructeur archivée sous `artifacts/.tmp-archives/chips/CPU/NEC/uPD780/uPD780C-1/UPD780C.pdf`, pages 4-8/4-9. Ce sont des bornes maximales et non les mesures d'une SG-1000.

Une réserve ne déclenche aucune différence inventée.

**Correction explicite utilisateur du 11 novembre 2026 : les réponses « conserver le modèle avec réserve » concernaient le Zilog, pas le NEC.** Leur attribution précédente au NEC était erronée. Il faut les caractériser et réaliser le comportement NEC établi avant de le déclarer conforme. Aucun second décodeur, séquenceur ou CPU ne sera ajouté.

## Reprise du 12 novembre 2026 — RESET et pilotage du bus

Source constructeur supplémentaire : [NEC Microcomputer Catalog 1982](https://ftpmirror.your.org/pub/misc/bitsavers/components/nec/_dataBooks/1982_NEC_Microcomputer_Catalog.pdf), archivé dans `artifacts/.tmp-archives/chips/CPU/NEC/uPD780/uPD780C-1/1982-NEC-Microcomputer-Catalog.pdf`. La section µPD780/µPD780-1, pages imprimées 392–393 (pages PDF 394–395), décrit RD et WR comme sorties trois états, HALT comme sortie avec exécution de NOP pour le rafraîchissement, et RESET avec adresse/données flottantes et toutes les commandes de sortie inactives. Elle ne précise pas le pilotage RD/WR pendant HALT, ni le reset court.

La fiche 24 pages, pages imprimées 4-4/4-5, affirme au contraire dans les descriptions individuelles RD/WR qu'ils flottent pendant HALT ou RESET ; sa propre description RESET annonce les commandes inactives. L’utilisateur retient explicitement le catalogue NEC 1982 pour RESET le 12 novembre 2026. Le modèle commun produit déjà ce pilotage : adresse/données flottantes, commandes inactives ; aucune branche NEC supplémentaire n’est nécessaire pour un comportement identique. La contradiction demeure documentée, mais RESET normal n’est plus marqué inconnu. Le marqueur est renommé `HaltBusDrive` (valeur binaire 2 conservée, format d’état inchangé) pour ne couvrir que le point HALT encore à établir. Aucun changement Zilog.

Vérification autonome : le test existant `NormalResetAbortsWaitClearsDocumentedRegistersAndRecovers` est devenu `NormalResetAbortsWaitOrHaltClearsDocumentedRegistersAndRecovers`, avec quatre cas Zilog/NEC × WAIT/HALT. RESET reste actif pendant quatre périodes de 250 ns, donc au-delà des trois clocks minimales. L'oracle vérifie PC/I/R, conservation AF, IFF1/IFF2, IM0, sorties adresse/données flottantes, huit commandes inactives et reprise par LD HL,1234. Cela teste le modèle du reset normal, pas la validité des impulsions courtes ni RD pendant HALT. Aucun comportement de production n'a changé.

`artifacts/TestsChips/Z80/SG-1000/20261112-nec-normal-reset.trx` : **120 succès Debug, zéro échec/ignoré**, durée rapportée 2 s, processus code 0. Groupe Z80 fonctionnel complet, mesure de performance exclue. Avertissement préexistant xUnit2031 dans `Shared/ArchitectureTests.cs:33`. Aucune nouvelle mesure de vitesse ni confirmation Release de cette version.

Question utilisateur envoyée le 12 novembre 2026, **réponse reçue** : « Pour RD/WR du NEC, les sources constructeur se contredisent : la fiche 24 pages annonce une haute impédance pendant HALT/RESET ; le catalogue NEC 1982 (p. 392–393) annonce les commandes inactives pendant RESET et des NOP de rafraîchissement pendant HALT, sans préciser RD/WR dans HALT. Autorises-tu à retenir le catalogue 1982 pour RESET, en laissant uniquement le pilotage pendant HALT non qualifié jusqu’à une preuve plus précise ? » Réponse exacte : **« Retenir le catalogue 1982 pour RESET »**. Puis consigne explicite : appliquer ce comportement et documenter la contradiction ; poursuivre les recherches HALT/RD/WR ; conserver les particularités NEC dans son profil sans modifier le Zilog. Les autres inconnues NEC restent ouvertes et ne bénéficient d'aucune acceptation de réserve Zilog.

Qualification du profil appliquée dans `Upd780C1Profile.cs`, `Z80BehaviorReservations.cs`, la validation de `Z80HardwareProfile.cs` et l’oracle de séparation des profils. `Z80BusSequencer.EnterReset` cite les deux références constructeurs pour son mécanisme commun. ### Précisions électriques et sources Epson/Sony

Précision utilisateur à conserver : **inactif ne signifie pas nécessairement activement piloté au niveau haut**. Un niveau haut mesuré avec rappel peut provenir d'une sortie flottante. Les formulations de la fiche NEC restent ambiguës et son erreur « HALT input » est établie ; l'opposition « inactif / haute impédance » ne constitue pas à elle seule une contradiction électrique démontrée. La décision RESET normal selon le catalogue 1982 demeure appliquée. Les tests vérifient la représentation retenue dans le modèle, pas une caractérisation électrique nouvelle du silicium.

Epson QX-10 **A-10, page PDF 63**, effectivement inspectée et archivée comme `Epson-QX10-TM-page-63-A10.png` : µPD780C/D-1, RD/WR/HALT sorties, RESET/BUSRQ entrées, concession en fin de cycle machine avec adresse/données/commandes trois états en haute impédance. La page décrit une horloge de 3,9936 MHz pour le QX-10. Elle n'établit pas le pilotage RD/WR pendant HALT ; la concession BUSRQ n'est pas transférée par analogie à HALT.

[Copie du catalogue NEC 1979](https://ftpmirror.your.org/pub/misc/bitsavers/components/nec/_dataBooks/1979_NEC_Microcomputer_Catalog.pdf) : même publication que la référence déjà consignée ; l'outil web refuse le document complet de 23 250 907 octets.
