# Arithmétique NMOS — référence constructeur relue le 11 novembre 2026

Source : Synertek, *SY6500/MCS6500 Microcomputer Family Programming Manual*, publication 6500-50, août 1976, réimpression autorisée MOS. [PDF consulté](https://device.report/m/3250fb584a5b7df3f380c54a14361898d0912f8f4ed9dc21643edfeb3032fa01.pdf). Pages imprimées 7–14 et 18–20 (PDF 18–25 et 29–31), annexe B-3/B-24 (PDF 192/213).

ADC additionne A, opérande et C. SBC retranche l'opérande et l'emprunt, complément de C. En binaire, les résultats sont sur huit bits ; C exprime la retenue ou l'absence d'emprunt, V le dépassement signé, N le signe du résultat et Z son annulation. Avec D, les deux chiffres BCD empaquetés représentent 00–99 ; le résultat décimal est corrigé automatiquement, avec C pour dépassement de 99 ou absence d'emprunt. Les opcodes immédiats 69/E9 prennent deux octets et deux cycles. Ces passages ne caractérisent ni les chiffres BCD invalides ni les indicateurs intermédiaires décimaux.

La note est une synthèse de lecture, pas le document original. Les téléchargements directs ont été refusés (Bitsavers 403 ; device.report challenge HTTP), alors que le lecteur web donne le PDF et ses pages. Aucun PDF local acquis n'est revendiqué. Le test autonome associé est `ArithmeticSpecificationTests.cs` ; ses attentes binaires utilisent des entiers et ses attentes BCD des nombres décimaux, sans reprendre les corrections de nibbles du moteur.
