# MC6809 — horloge E, interruptions et CWAI

## Passage du 8 novembre 2026

Les niveaux IRQ/FIRQ/NMI sont conservés dans le CPU par SetIrq/SetFirq/SetNmi. La carte raccorde les sorties réelles du VIA et du 8271 ; aucun fournisseur d'interruption n'est consulté à chaque cycle. L'échantillonnage NMI reste dans Tick, avec les mêmes masques, priorité et condition d'initialisation de S. Aucun thread ni nouvel ordonnanceur.

Défaut établi : CWAI comptait 20 cycles avant l'attente puis encore 7 pour la vectorisation. Le minimum Motorola de 20 cycles comprend cette vectorisation. La séquence est 16 cycles avant attente (opcode, masque, lecture suivante, cycle interne, 12 octets empilés), puis quatre cycles : interne, vecteur haut, vecteur bas, interne. Les cycles d'attente s'y ajoutent. Les autres prises d'interruption restent inchangées.

Le moniteur Acorn 6809 lisait seulement sept octets disque : son service dérivait à 67 cycles pour des demandes espacées de 64 cycles E. Après correction du CPU, le même montage, la même horloge E de 1 MHz et le même 8271 lisent 512 octets et exécutent le programme chargé (RAM 2010=5A). Aucun ralentissement du contrôleur pour masquer le défaut.

61 tests CPU Debug passent, 71 ms ; entrée sans sondage, pile, masques, NMI, IRQ, FIRQ, bus et CWAI. Le banc de carte complète System 3 mesure 14,063276 ms/champ, 71,107 champs/s sans limite et 1,422144 MHz effectifs (142,214 %). Cette mesure couvre le montage, pas le CPU isolé.
