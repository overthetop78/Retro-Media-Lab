5V,25°C,RL667Ω : données tPLH8/max13 ns,tPHL10/15 ; sélection16/21,17/24 (CL45pF). Activation tPZH15/30,tPZL19/30 (CL45pF), désactivation tPHZ18/30,tPLZ16/25 (CL5pF). Les causes simultanées retiennent le délai maximum des trajets concernés ; pulses courts/hazards non caractérisés, modèle nominal inertiel documenté pour poursuivre.

Le suffixe B augmente le courant de sortie par rapport au LS257 original ; le schéma de la machine n’identifie pas ce suffixe. Les commandes de manette et le tirage externe du bus appartiennent au câblage machine, pas au multiplexeur.

### Variante EmuChip : transport natif du13novembre2026

L'implémentation originale de cette puce n'est pas modifiée. Sa variante sous src/RetroMediaLab.Chips/EmuChip consomme les mots électriques datés dans son propre moteur et adapte les contrats historiques lorsqu'ils sont utilisés. Les profils matériels, états sauvegardés, phases, délais et qualifications restent identiques dans les comparaisons couvertes. Le lot CPU–logique–mémoires retire les constructions/redécodages des contrats dans le trajet normal de la SG-1000; il ne retire aucune transaction matérielle.

Vingt-sept contrôles composants et six contrôles machine passent par configuration. Les comparaisons incluent les entrées ternaires et propagations logiques, les mémoires connues/inconnues/coïncidentes, puis les trois ROM sur fenêtres appariées et120images longues. Le gain Debug du lot complet est9,35–17,47 % au démarrage et15,18–21,26 % sur la fenêtre après30images; ce n'est pas un débit isolé de cette puce. Release reste variable, dont un écart Castle défavorable. Les preuves, propres/inclusifs et limites de résolution du profil se trouvent dans [l'étude Sega](../../project/emulations/Sega/segaemu-performance-architecture.md), section Résultats Q.
