# TI SN74LS374

Référence constructeur : [TI SDLS165B](https://www.ti.com/lit/ds/symlink/sn74ls374.pdf), octobre 1975, révision août 2002, pages 1 et 3–5. Archive locale : `artifacts/.tmp-archives/chips/Logic/TexasInstruments/SN74xx/SN74LS374/sn74ls374.pdf`.

Huit bascules D capturent simultanément sur le front montant de CLK. Entre ces fronts, le registre conserve sa valeur. OC haut place les huit sorties en haute impédance, sans inhiber le stockage ; OC bas rétablit les données conservées. Aucun reset n'existe. L'état initial du registre n'est pas garanti. Le 74LS373 transparent n'est pas cette variante.

Le modèle numérique distingue valeur inconnue et sortie non pilotée par le couple valeur nullable/autorisation de pilotage. Fréquence déclarée, CLK, fronts reçus et registre appartiennent au composant. Les notifications signalent uniquement un changement de valeur résolue ou de pilotage ; elles ne remplacent pas les fronts internes.

Application constatée, non encore raccordée : IC12 de la VDU80 Acorn 400,019, manuel System 5 §2.5.1 et nomenclature page 15. Entrées caractère sur sept bits, DE sur le huitième, CLK 2 MHz'. Le code SystemVideo actuel lit directement le caractère et dessine ses six points ; le latch réel et le 74LS165 doivent remplacer ce chemin pour représenter la capture puis la sérialisation.

## Réalisation et vérification — 9 novembre 2026

Composant dans `RetroMediaLab.Chips/Logic/TexasInstruments/SN74xx/SN74LS374/`, interface et service séparés, sans état temporel dans la carte. OC est mémorisé et agit immédiatement sur le pilotage ; les données ne changent le registre qu'au front montant. Les périodes groupées ne franchissent aucun changement observable sans le notifier ; les callbacks peuvent modifier les entrées pour le front suivant. Aucune ressource hôte ni entrée relue chez un fournisseur. Aucun reset fictif ni valeur de mise sous tension garantie.

**10 contrôles permanents Debug réussis**, zéro échec/ignoré, 64 ms. Couverture : 256 motifs et huit bits, niveaux répétés sans double front, maintien entre fronts, OC indépendant du stockage, inconnue initiale distincte de haute impédance, feedback, 0/1/2/257 périodes groupées contre niveaux explicites et leurs notifications, 1001 périodes stables/masquées, validation des fréquences et préconditions de période.

Mesure isolée Debug normale hors RML, sans autre test ou compilation : 100 000 périodes de chauffe puis trois fenêtres de 2 000 000 périodes complètes, SetData et Clock inclus. Sortie raccordée à un observateur ; 2 000 000 fronts vérifiés par fenêtre.
