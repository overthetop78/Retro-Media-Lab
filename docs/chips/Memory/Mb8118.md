16K×1,7adresses multiplexées row/column, sorties trois états. Page7 :128lignes doivent être rafraîchies en2ms ; RAS seul rafraîchit la ligne capturée, CAS reste haut. Rafraîchissement caché : CAS maintenu bas après une lecture conserve DOUT pendant les cycles RAS. DOUT est un latch indépendant, reste valable après RAS haut, devient Hi-Z au CAS haut (tOFF). Écriture anticipée : WE bas au CAS descendant,DIN capturé par CAS ; écriture tardive/RMW : DIN capturé par WE descendant, sortie de lecture conservée jusqu’à CAS haut. Page mode conserve la ligne et présente plusieurs colonnes à chaque CAS.
