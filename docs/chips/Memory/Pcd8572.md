- Microchip, PCD8572, DS20016E (1989), pages 3–7 : [fiche constructeur](https://www.repeater-builder.com/motorola/r100/r100-eeprom/pcd8572-clean.pdf). Copie et huit images de pages : `artifacts/References/Chips/Memory/PCD8572/`.

Copie locale déjà présente : `artifacts/References/Machines/Acorn/BBC Master Compact/Input/Acorn_MasterCompact_SM.pdf`.

IC24 utilise SDA/PB4 et SCL/PB5. A0–A2 sont à zéro ; le montage possède R1=12 kΩ et C2=2,2 nF. Ce n'est pas une RTC HD146818. La communication suit les fronts SCL fournis ; aucun oscillateur de transmission indépendant n'est ajouté.

## Revue et corrections du 8 novembre 2026

Le modèle courant est `src/RetroMediaLab.Chips/Memory/Generic/I2C/EEPROM128/Services/CompactEeprom.cs`.

- Défaut corrigé : START/STOP comparait la commande SDA du maître, même si le composant maintenait SDA bas. Le modèle compare maintenant les niveaux résolus avant/après et échantillonne la ligne résolue au front SCL.
- Défaut corrigé : BeginTransmit incrémentait le pointeur avant même réception de l'octet. DS20016E page 6 impose son incrément après ACK du maître. L'incrément est déplacé à ce front ; NACK et interruption ne consomment plus une adresse.
- Les états SCL/SDA, le registre de décalage, le pointeur et les phases de handshake restent dans le composant. Aucun thread ni traitement périodique de surveillance n'est ajouté.

Revue statique seulement : aucun test/build, aucune preuve d'exécution ni gain chronométré nouveau.

## Partie encore manquante : effacement/écriture

Le code écrit encore immédiatement chaque octet reçu dans le tableau. Le composant réel déclenche son cycle après STOP et accepte un ou deux octets par séquence ; cette fonction reste à réaliser avant clôture.

La fiche fournit des durées différentes selon sa rubrique : environ 20 ms par octet dans le texte, 30 ms typiques dans la table (20–100 ms, R=10 kΩ/C=2500 pF). Elle ne donne pas la loi pour le RC du Compact. Ne pas présenter une durée choisie comme celle mesurée sur la carte ; clarification demandée avant de fixer ce comportement temporel.

## Complément de revue : adresse physique et données de carte

Les huit combinaisons A0–A2 décrites par le constructeur sont maintenant acceptées au constructeur. L'adresse de réception compare `1010 A2 A1 A0 R/W` aux straps fournis ; le constructeur sans paramètre conserve le montage zéro du Compact. Les adresses hors des trois bits sont refusées avant initialisation.

Les 17 octets de configuration Compact étaient initialisés dans le composant mémoire générique. Ils sont maintenant définis dans `CompactNonvolatileMemoryConstants` du module Acorn puis importés au montage. La mémoire initiale du Compact reste identique, sans transformer ces valeurs de configuration en valeurs de reset de toutes les puces PCD8572. Les images persistantes continuent de passer par les fonctions Import/Export existantes. Source seulement : aucun nouveau test ni build effectué.

La fiche d'origine General Instrument DS20016D reproduit la même différence entre texte et table : [Non-Volatile Memory Data Book 1985](https://bitsavers.trailing-edge.com/components/gi/_dataBooks/1985_GI_Non-Volatile_Memory_Data_Book.pdf), pages PDF 125 et 127 (pages imprimées 2-61 et 2-63). Elle ne résout donc pas le choix temporel en attente ; aucune formule RC n'en est déduite arbitrairement.
