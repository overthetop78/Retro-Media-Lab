### Géométries du moteur partagé avant raccordement SG-1000

Les schémas de cartouches déjà archivés (`sg8+8.png`, `sg48k.png`, cités dans la fiche machine) nécessitent des ROM de8/16K en plus de32K. Le mécanisme existant est déjà partagé avec les profilsNEC/Fujitsu, mais la capacité restait imposée à32768dans le moteur. L’extension doit porter la géométrie dans le profil commun, sans padding d’une image8K pour la faire passer pour une puce32K, ni second décodeur. Les profils constructeur déjà caractérisés gardent exactement leur capacité32K et leurs paramètres. Un profil de géométrie générique doit porter son identité explicite et sa qualification électrique ; définir8/16K ne prouve ni fabricant ni suffixe ni délai. L’utilisation future d’un profil logique non caractérisé dans la machine devra rester explicitement distincte d’un profil fabricant acquis.

`Tmm23256Timing.Capacity` porte désormais8192/16384/32768octets et `ElectricallyCharacterized` distingue une géométrie logique d’un profil électrique acquis.
